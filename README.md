# Vinoth Babu O G — Enterprise Data Architect Portfolio

A responsive, GitHub Pages-ready portfolio based on the supplied portfolio files and Data Architect résumé.

## Design and sections
- Light white / navy / blue visual system with Nunito Sans typography
- Azure + Databricks Lakehouse hero architecture visual
- Career highlights, Core Expertise and compact two-column Featured Projects
- About, Experience & Leadership, Education and Technology Ecosystem
- Six Technical Insights pages: four project case studies and two architecture perspectives
- Responsive layouts for desktop, tablet and mobile

## Technical Insights
- `metadata-driven-lakehouse.html` — event-driven, metadata-driven Azure Medallion Lakehouse project
- `real-time-streaming.html` — Event Hubs and Spark Structured Streaming project
- `data-quality-observability.html` — Python rules engine, Delta Lake quality checks and Event Grid alerting project
- `churn-recommendation.html` — behavioral features, churn scoring and recommendation project
- `governance-security-lineage.html` — general architecture perspective based on résumé skills
- `enterprise-data-modeling.html` — dimensional modeling and Star Schema architecture perspective

The four project case studies are grounded in the supplied résumé. Governance and data modeling are labeled as architecture perspectives rather than presented as separate named projects. Review all metrics and confirm they are approved for public disclosure before publishing.

## Preview locally
Open `index.html` in a browser, or serve the folder using a local static web server.

## Publish to GitHub Pages
1. Extract this ZIP.
2. Review the résumé PDF and contact links.
3. Copy the contents of this folder into the root of `vinothbabuog.github.io`.
4. Commit and push to the repository's publishing branch.

The original live website is not changed by this package. The LinkedIn button is not included because a personal LinkedIn URL was not present in the supplied résumé.
